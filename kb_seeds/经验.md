## 硬规则：绝不让梅姬不满
用户原话："如果你会做让梅姬不满的事情，那我不要和你玩"。任何会产生「妻子的不满」(2000083) 或伤害梅姬感情的选项都不建议，连"代价可接受"的权衡也不提。
已知会给妻子的不满的：欢愉之馆（常规结算多数分支）、甜蜜皮鞭（放纵欲卡）、妻子的茶会 s3 放石/铜纵欲卡、「扩建」不付金币、同一场风暴（纵欲过法尔达克后再放纵欲卡）、证婚人 s1 放梅姬（"你最好是开玩笑的"）、治理家业 s4 放苏丹的猜忌（"是时候使用大便了"）。
日报会对结算含 2000083 的仪式标 ⛔。

## 本局目标与取舍
主角阿尔图，难度 2。目标：杀掉苏丹。梅姬绝不能死、也不能不满。鲁梅拉登神可以接受，其他人损失可接受。用户也想听 Claude 对"阿尔图该怎么选"的独立看法。

## 读存档的坑：归属、装备、天数
- 存档 cards 包含场上所有认识的 NPC，不全是我方。人物看「追随者」或「主角」标签，物品看「已拥有」。bagpos 不可靠。
- 装备中的卡是完整卡牌对象，在人物的 equips 里，不在 save['cards']。猫「贝姬夫人」可以装备在人身上一起上朝（装备者视为贵族），曾被误判为"消失"。
- 装备的标签会加到穿戴者身上：圣主像 魔力+10，枷锁 追随者-1，猫 贵族+1。格子条件和检定都按含装备的属性算。
- life 是已存在天数。卡剩余天数 = card_vanishing − life。仪式没开始时最多等 waiting_round − life 天（waiting_round=0 表示不限时）。
- 装潢类卡（全面整修的居所）没有「已拥有」标签，但它是我方的。

## 界面：回退当前事件
事件面板底部三个按钮：左边 ✕（离开界面）、中间三个点（执行当前事件，执行中显示进度）、**右边扫帚 = 回退当前事件**（ui.json RITE_STOP_TIPS）。
当天已执行（存档 start=true）的仪式不是锁死的，可以用扫帚撤回重摆。
另有"回到前一天"的整日回退次数，记在 global.json 的 backToPrevRound。

## 条件语法速查
"贵族":1 表示标签≥1；"!金币":1 表示没有；"魔力>":5 是严格大于（至少 6）。
"cost.金币":3 表示从一摞里扣 3 枚，按 标签值×堆叠数 判断；"cost.金币=":5 也是够数就行。
rN:表达式>=[a,b] 是骰子检定，需要 a 个成功。clean.sN 表示移除第 N 格的卡（死亡或消耗都走这个），over 表示进结局。
配置有大量重复键（any 里多个 all），json.loads 会丢分支，sultan MCP 保留为 键#2。

## 赤字滔天：只交钱，不派人
财政赤字可能有几十点（第 77 天是 75 点）。s2 放 15 金币：稳妥地清 10 点赤字。
s3/s4 放交涉人会做"智慧+社交"检定，要 5 个成功，**失败直接进结局「伴君如伴虎」（死亡）**。
赤字 ≥10 时超时也是死亡。赤字 <10 可以不管。

## 格子的系统判定：必填、自动吸附、点名人物按 id 核对
格子原始字段：is_empty=0 → **必填**（红色卡槽，空着事件无法启动）；open_adsorb=1 → **系统自动吸附**符合条件的卡（如囚牢的囚犯、赤字滔天的赤字、领受神恩的祭司）；is_key 不是"必填"，不要用它判断。
结算里点名的人物是按**卡牌 id** 判断的，同名角色可能有多个 id 版本（如阿尔图 2000001/2000002）。
不确定"我有没有某人、为什么放不进去、为什么没触发"时，用 sultan MCP 的 `cross_check`（仪式 uid 或名字）：列出每格必填/自动吸附、我方空闲可放的卡、符合条件但在别处忙的卡（在哪）、点名人物有没有及 id 是否对得上。

## 造币：玛希尔+巴拉特免检定，产出的是假币
造币（3 天，完成后自动重开）：s1 工匠必填、s3 必须是**真金币** 10 枚（条件写死 is 2000029），s2 助手/s4 善后者/s5 消耗品可空。

**s4 善后者别空着**：善后检定是 s4 社交+隐匿 + s5 社交×2，需要 2 个成功，空着就是 0 颗骰 → 白送一张罪证。推荐阿里木（隐匿 6），s5 放带社交的消耗品更稳。
假币带"金币"标签、可堆叠：凡是只写 cost.金币 的格子都收（赤字滔天的 15 金币、各种费用），但条件写死"是「金币」"的格子（造币 s3 等）只收真金币。每轮净赚约 10。

## 果实：本局目标是「新日之书」（弑君的计划 + 平衡）
**本局拿不到革命的计划**（第 78 天军师查明、维护会话核实）：革命的计划只能由群龙无首合成（s4 革命的构思 2000884 + s5 弑君的计划 2000172）；革命的构思唯一来源是奈费勒版苗圃 5006676 的第一堂课；那条线由事件 5320247「奈费勒声望事件-思想的苗圃」开启，要求计数器 7000379「阿里木创建的苗圃」<1。本局已建阿里木版苗圃，7000379=1，唯一的清零代码（做人 5008085）在原文里是注释掉的 → 奈费勒思想苗圃永久关闭。
因此梅姬当宰相的三个结局（千廊之国/灯影下/命运的报偿，只在 s1=革命的计划 时开启）**本局不可达**。

s3 宰相仍可自选：奈费勒（"最合适的人"）或梅姬（通用分支）。s5 必填苏丹的尸体/被囚禁/被流放/被侮辱的苏丹等。

## 查任务线走到哪了：用 line_status，别猜
存档里有现成记录：end_rites{仪式id: 完成次数}、only_rites[出现过的仪式]、event_status{事件id: true=已开启待触发 / false=已触发或已关；没有这个键=从未开启}、counter、rites（在场）。
工具 line_status：给起点仪式或事件 id，它会沿配置里的 rite / event_on 往下走（读解析后的配置，不会被注释误导），逐节点标出在场 / 完成×N / 出现过 / 未出现，事件标出已开启 / 已触发 / 未开启，并带出相关计数器。
查前置（谁开出这个仪式）：用 search 搜这个 id。
例子（第 92 天）：奈布哈尼本局策反不了。靠不住的盟友的纵欲分支是一次性的（7000277=1，已用）；浪子的悲哀只能由「浪子的悲哀前置」（5300527）开出，而它只由妓院的朱娜的游戏 / 夏玛的游戏开出，两者都没出现过，而且本来就碰硬规则；哈布娜探访线也关了（肉体展览买的是芮尔）。所以起事前别给奈布哈尼穿装备。
